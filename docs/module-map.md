# Module map

One entry per module of `src/mcp_audit/`, with the facts a contributor needs
before changing it: which finding IDs it owns, where it runs in the pipeline,
its budgets, and the tests that pin it. `CLAUDE.md` has the short tree; read
the entry here, and the module's own docstring, before you change a module.

This text moved here unchanged from `CLAUDE.md` on 2026-11-21, so that file
stays short enough to read. Keep each entry true when you change its module.
